# Atlas

Atlas是一款简单、易用的NAS导航页，前端基于`Vue3`框架开发，使用`Vite`构建。后端基于微软的`Minimal API`框架开发，使用`AOT`模式发布，能有效降低打包体积和内存占用。

更多信息请查阅 **[文档](https://mrkinte.github.io/Atlas-Docs/)**

![](https://mrkinte.github.io/Atlas-Docs/images/docs/introduction/sample-dark.png)

## 演示站点

- [Atlas Demo](https://atlas.mrkinte.dpdns.org) （服务器在国外，访问速度可能受限）

> [!TIP]
> 演示站点已默认登录，但所做的任何修改都不会写入后端，刷新后失效。

## 特点

- 将首页的功能独立成一张张卡片，可以依据自己的喜好进行布局。

- 引入了Live2D模型解析功能，且提供配套的编辑工具 [Live2D Studio](https://github.com/Mrkinte/Live2D-Studio)，可以方便的将自己的Live2D模型修改为适合Atlas展示的状态。
